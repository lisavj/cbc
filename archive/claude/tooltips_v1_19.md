# CBC EMA Slope v1.19 input tooltips (removed in v1.20 for the token limit)

Input variable -> tooltip text, in script order.

- **bot_on**: v10.71: add CBC a second time on the chart, turn this on there only, and create that copy's 'Any alert() function call' alert with your CrossTrade webhook URL. Your normal CBC copy and its dashboard alert stay unchanged. Never share or publish a chart with the key filled in.
- **bot_risk**: v10.78: 0 = always the Contracts above. > 0 = size each trade from its stop: contracts = floor(risk / ((|Entry - SL1| + the limit ticks) x point value)), at most the max below. MES: 1 pt = $5, so a 12-pt SL1 is $60 per contract and a 41.7-pt SL1 is $208.
- **bot_mode**: Limit + cancel (default): limit at CBC Entry +/- the ticks below, TP1 / SL1 as absolute prices, cancelled after the minutes below if not filled -- a late alert does not chase price. Market + ATM: market entry, TP1 / SL1 as tick distances from the actual fill (no stale-alert protection).
- **bot_age**: v10.73: the entry order expires this many seconds after CBC sends the alert (GTD). If TradingView delivers the alert later than that, no trade opens. 0 = off (cancel after the minutes above instead). Test on demo first: TP1 / SL1 must stay in place after the cutoff once filled.
- **bot_t_fl**: The setup's FIRST listed trigger decides. Live 10/19-11/05 MES 3m: Flip 14 ended +6.0, LTF Pierce beyond EMA9 13 ended +11.8.
- **bot_d5**: v10.86: bot only (bot copy / bot preview); CBC setups and alerts unchanged. EMA 5 of the previous daily closes.
- **bot_win**: v10.74: the bot only OPENS trades on candles closing inside one of these New York time windows, e.g. "0930-1145, 1300-1545" or "1800-0200" (may cross midnight). Empty = any time. Closing trades (CBC end, 15:57 flatten) is never blocked. The NY opening-range block (9:30-10:00) and "No new entries from" below still apply.
- **bot_eodt**: v10.72: the first candle CLOSING at or after this time (New York) flattens an open bot position (until 18:00 ET). Default 1557 = the 15:54-15:57 candle on 3m, so the order reaches the broker before 15:59 ET even with a few seconds of alert delay.
- **bot_noet**: v10.72: no new bot entry on a candle closing from this time (New York) until 18:00 ET.
- **bot_news**: v10.94: no bot ENTRY on a candle closing within ± the minutes below of any time listed here (exits are never blocked). One date per line (or comma-separated), then its event times in New York time, 24 h: "1113 0830", "1114 0830 1000". Add a year for dates far ahead: "20270108 0830". Enter as many weeks / months as you like; past dates are simply ignored. Empty = off. A typo stops the script with an error naming the entry.
- **bot_eow**: v10.89: inside these New York windows the bot sends entries only -- no flatten when CBC ends the setup and no exit-rule flatten; the broker-side TP1 / SL1 bracket closes the trade. Outside them entries and exits as usual. The 15:57 end-of-day flatten and flatplace on a new setup still apply. Example: "1830-2200, 0300-0930".
- **bot_eof**: v10.90: inside the entry-only windows, ON = the bot still flattens when CBC ends the setup on an HTF (15m) CBC flip against it; 16:00 / time-stop ends stay suppressed. OFF = only the TP1 / SL1 bracket (and the 15:57 flatten) close the trade there.
- **bot_fow**: v10.91: a bot entry on a candle closing inside these New York windows is sent without take-profit and is closed only by a confirmed HTF CBC flip against it, its SL1 (if kept below), the end-of-day flatten or the next bot entry. Example "0930-1600".
- **bot_foall**: v10.92: which bot trades use the flip-only exit inside the windows (by the setup's FIRST listed trigger). Other trades keep the normal TP1 / SL1 bracket.
- **bot_pv**: v10.76: on the copy with Bot copy OFF, sends "• Bot Order (preview)" alerts (the same orders the bot copy sends, without the secret key) to your normal alert webhook; see the dashboard Bot tab. Keep the bot settings identical in both copies.
- **auto_trade_setup_enabled**: Draws an entry/stop/target box+lines, sized from the live pivot pool below, the moment a trigger fires. Visual forecast only — Pine indicators cannot place real orders; pair this with your own execution or a webhook-driven automation if you want it to actually trade.
- **ats_allow_toward**: On (default since v8.37): toward-flip setups are allowed and marked "Flip side: TOWARD" (yellow outline in the Alert Feed). Off: setups only come after an 'away' HTF CBC flip (long flip closing ABOVE the HTF EMA20, short flip closing BELOW it). A 'toward' flip (long below / short above the HTF EMA20) draws no flip setup, and no pierce setups follow it until the next flip. On: toward flips count too, for every setup trigger. Alerts and markers are not affected.
- **ats_tw_late**: v9.55: only while 'Include toward HTF flips' is OFF. After a TOWARD HTF CBC flip, the first confirmed candle that closes at least this many points beyond the HTF EMA20 on the away side (above it for a long, below for a short; 0 = any close beyond it) counts as the flip: the HTF CBC Flip setup draws on that candle and the other triggers are allowed from then on, until the next HTF flip.
- **ats_tw_sym**: v10.60: overrides the toward-flip late-away line above for the listed symbol / chart timeframe, e.g. "MNQ 3m 0, MES 3m 0, MGC 2m 2". A value > 0 = ON with that many points; 0 = OFF (after a toward flip no setups at all until the next away flip); unlisted charts follow the checkbox and points above. Default "MNQ 3m 0, MES 3m 0" from the 11/03 toward-flip study (Jan-Nov replay: late-away OFF better in all three thirds on MNQ 3m, +1518 pts, and MES 3m, +262; worse on MGC 5m and MNQ 5m, so they keep it).
- **ats_fd_mode**: v9.71/v9.78: default = x ATR from 3m EMA20, 2.0. Off = no limit. Otherwise, on the candle where the HTF CBC Flip trigger fires (incl. the late-away candle and the pullback-wait entry), the flip setup is skipped when |close - EMA20| is more than this distance, in points or in multiples of the setup ATR (ATR length above). Only the flip trigger is gated; other triggers are unchanged.
- **ats_fd_pts**: v9.89: the flip distance limit is the LARGER of the x setting above and this per-symbol point value (same symbol list format as Min SL). Unlisted symbol = x setting only. Empty = off.
- **ats_fva_on**: v9.72: OFF (default) = no check. ON = on the candle where the HTF CBC Flip trigger fires (incl. the late-away candle and the pullback-wait entry), a long needs close > VWAP + X and close > EMA200 + X; a short needs close < VWAP - X and close < EMA200 - X. Otherwise the flip setup is skipped. Only the flip trigger is gated. 0 = just beyond both.
- **ats_fl2_sym**: v10.77: e.g. "MGC 2m 1" (1 = on, 0 = off for that chart; same format as the other per-symbol lists). On a listed chart no setup is drawn while the current HTF flip carries the "Flip flop: crossed ..." warning (EMA 200 / VWAP below the flop %, or a pivot), except when the HTF CBC Flip trigger fires on that candle (flip setups use the checkbox above). Empty = off everywhere. Basis 11/05: MGC 2m non-flip setups with the warning 43 / -71 pts, both halves negative.
- **ats_fer**: v9.95: 0 (default) = off. Above 0 = an HTF CBC Flip setup needs the Efficiency Ratio (Trade Setup Filters chop length) on the flip candle to be at least this value, e.g. 0.30. Other triggers are not affected; the general ER filter in ③ still applies to all setups.
- **ats_erl**: v9.96: per-trigger minimum Efficiency Ratio on the trigger candle (same ER as the ③ filter). 0 (default) = off. LTF EMA20 Pierce (incl. late) / HTF EMA9 Pierce / HTF EMA20 Pierce (incl. late). Not lifted by the ③ breakout exception.
- **ats_e2s**: v9.90: OFF = no check. ON = an HTF CBC Flip setup needs the EMA200 now vs one HTF candle ago (e.g. 5 x 3m) to slope in the trade direction.
- **ats_vws**: v9.90: OFF = no check. ON = same as above for VWAP (resets at the session start, so the first HTF candle compares against the new VWAP).
- **ats_h20s_on**: v9.73/v9.75/v9.76: Off (default) = no check. Slope = the live HTF (15m) EMA now minus its value one HTF candle ago, in points. Long needs slope >= min, short needs slope <= -min (min 0 = flat or better is OK; e.g. 0.5 = must have risen/fallen at least 0.5 pts over the last HTF candle). Both = EMA9 AND EMA20 must each pass. Applies to every trigger.
- **ats_vw_blk_on**: v8.78: HTF CBC short: once a candle closes below VWAP and a later candle closes back above it, no SHORT setup (any trigger) on that candle and the next N candles. Long mirrored (close above VWAP, then back below blocks LONG setups). Resets at each confirmed HTF flip.
- **ats_pv_blk_on**: v8.79: same rule as the VWAP reclaim, for each of R1, R2, R3, S1, S2, S3 (not PP). HTF CBC short: a candle closes down through one of them and a later candle closes back above it -> no SHORT setup on that candle and the next N (the VWAP bars box). Long mirrored. Resets at each confirmed HTF flip.
- **ats_req_clear**: v8.35: setups (every trigger) and High Confluence Setup only fire when the bar closes beyond BOTH EMA9/20 clouds: above the chart and HTF clouds for a long, below both for a short. Note: HTF Pullback triggers fire INSIDE the HTF cloud, so with this on they will almost never draw a setup; HTF EMA20 Pierce rarely will.
- **ats_req_htf9**: v8.70: part of "Require price past both EMA clouds". ON = a long also needs the close above the HTF EMA9 (short: below). OFF (default) = the HTF EMA9 is ignored.
- **ats_req_htf20**: v8.70: same for the HTF EMA20. OFF (default) = ignored.
- **ats_alert_on**: Fires an alert() each time a new setup draws: direction, trigger, TP2/TP1/Entry/SL1/SL2 with pivot names and points from entry. The Alert Feed page (index v27+) shows the latest one in a box at top left. Needs an alert on this indicator set to 'Any alert() function call'.
- **auto_trade_setup_show_tp2**: Shows the second target zone (TP1→TP2). Independent of Show SL2.
- **ats_fl_col**: v10.53: live only. When a new Trade Setup is drawn, a thick border around Entry / TP1 / SL1 blinks (on / off with every price update) from the setup candle through the next N candles (default 2), then disappears. Stops early if the setup ends. Not drawn on history (TradingView redraws past bars without updates, so nothing can blink there).
- **auto_trade_setup_show_sl2**: Shows the second stop zone (SL1→SL2). Independent of Show TP2.
- **ats_keep_old**: On (default): when a new setup draws, the previous one stops extending at that bar and stays on the chart. Off: a previous setup is kept only if price touched its TP1/SL1/TP2/SL2; an untouched one is replaced.
- **ats_one_on**: v9.61: ON (default) = while the latest setup is still live (not ended by SL1 / trail, TP2, HTF flip, 17:00 or replacement), a new setup in the SAME direction is not drawn (no box, no Trade Setup alert). An opposite-direction setup still draws. OFF = every trigger draws its own setup.
- **ats_kn_on**: v9.31: ON = setups still auto-draw, but when a new one draws only it and this many earlier setups stay on the chart (rolling); every older setup (boxes, lines, labels, trail steps, ⓘ) is erased. 0 = only the newest setup. v9.33: ON, 5 back by default. OFF = earlier setups stay per the option above.
- **ats_min_sl_on**: v9.53: per symbol. If SL1 (or SL2) is nearer to Entry than the listed points for this chart's symbol, it is pushed out to exactly that distance (pivot column shows 'Min N'). A stop already farther away is unchanged. Format: SYMBOL points, comma separated (MGC 6, MES 6 ...). Full-size contracts use the micro's value (GC = MGC, ES = MES, NQ = MNQ, RTY = M2K, CL = MCL); BTC = MBT or any BTC symbol. Not listed or 0 = no minimum. Wins over the Max ATR SL1 cap if larger.
- **ats_msl_sym**: v10.28: overrides the line above for a symbol and/or chart timeframe, e.g. "MGC 3m 0, MES 3m 0" = no fixed minimum on the 3m charts (the SL is then just SL1 x ATR). A listed value > 0 replaces the minimum; 0 removes it; unlisted charts keep the per-symbol minimum above. Replay 10/12-10/19: the 5-pt floor made the MGC 3m stop ~2.3 ATR while 90 % of winners never went more than ~1.1 ATR against.
- **ats_atr_sl_on**: v8.60: OFF = current method (SL1/SL2 = nearest pool levels beyond entry). ON = SL1 = Entry -/+ SL1 x ATR, SL2 = Entry -/+ SL2 x ATR, using the chart-timeframe ATR on the setup candle. v8.61: the other method's SL1/SL2 are always shown too (Trade Levels table, darker red, in price order; alert lines SL1/SL2 ATR or SL1/SL2 Piv) for comparison. Stops stay fixed (no auto re-pick to pool levels; dragging a handle still works). Minimum SL distance still applies. TPs unchanged.
- **ats_slm**: v10.01: where SL1 goes. ATR / pivots = the SL method above (default). 15m CBC flip level = the low (long) / high (short) of the last CLOSED HTF (15m) candle, i.e. where 15m CBC would flip against the trade. Last 15m close = the close of the last CLOSED HTF (15m) candle. Both: clamped to the Max ATR SL1 cap and the Minimum SL distance per symbol; if the level is on the wrong side of Entry (or missing) SL1 falls back to ATR / pivots. SL2 is pushed out to at least SL1. Trade Levels / alert show the distance as x ATR. Works best with SL method 3m ATR ON (with pivots the auto re-pick can pull SL1 to a nearer pool level).
- **ats_slx_sym**: v10.28: SL1 = Entry -/+ this many x ATR for the listed symbol / chart timeframe, e.g. "MGC 3m 1.3, MES 3m 1.3"; unlisted charts use SL1 x above (1.7). Replay 10/12-10/19: 1.2-1.3 ATR beat 1.7 + 5-pt minimum on MGC 3m and MES 3m in both halves of the data; 2m not better (keep 1.7).
- **ats_ts_sym**: v10.28: before TP1, the setup ends at the close of the candle where this many candles have passed and the best move in the trade direction is still below x ATR (next box). E.g. "MGC 3m 10". Unlisted charts: off. Ends as "Ended: Time stop" (exit marker TS). Replay: MGC 3m +8 pts with SL 1.3 ATR; no effect on MES 3m.
- **ats_atr_tp_on**: v8.62: separate from the SL switch. OFF = TP1/TP2 = nearest pool levels beyond entry. ON = TP1 = Entry +/- TP1 x ATR, TP2 = Entry +/- TP2 x ATR (same ATR length as the SL method). Targets stay fixed (no auto re-pick). The other method's TP1/TP2 are always shown too (Trade Levels table, darker green, in price order; alert lines TP1/TP2 ATR or TP1/TP2 Piv).
- **ats_f_chop_on**: v8.65: Choppiness Index (chart timeframe) = 100 x log10(sum of true ranges / (highest high - lowest low)) / log10(length). Above ~61.8 = sideways / range-bound, below ~38.2 = trending. No new setup while it is above the threshold.
- **ats_f_chop_len**: v9.35: lookback N for the Choppiness Index and the chop filters below (ADX, Efficiency Ratio, crosses, slope, range).
- **ats_c_adx_on**: v9.35: ADX (length N) below the value = no trend strength -> no new setup. ~20 is the classic line.
- **ats_c_er_on**: v9.35: Kaufman Efficiency Ratio = |close - close N bars ago| / sum of every bar's |close change| over N. 1 = straight line, near 0 = back and forth. Below ~0.3 = chop.
- **ats_er_bo**: v9.94: the Efficiency Ratio block is lifted on the candle that closes through the last LTF swing high / low or any session opening-range high / low (NY / London / Asia), and for the next bars up to this count (1 = that candle only). Other filters still apply.
- **ats_er_bs**: v10.11: OFF (default) = the ER block is lifted on the breakout candle and the following candles up to the bars above (3 = breakout candle + 2 after). ON = the breakout candle itself stays blocked; only the candles after it, up to bars - 1 (3 = the 2 candles after), are let through. 1 + ON = never. Replay 10/12-10/16: low-ER signals ON the breakout candle mostly lost, the 1-2 candles after were positive (small sample).
- **ats_er_bg**: v9.98: background colour by ER (length = Chop filters length): dark red = 0 to 0.05, red = over 0.05 to 0.10, orange = over 0.10 to 0.15, yellow = over 0.15 to 0.20, green = over 0.20 to 0.23, no shade = above 0.23. Exact ER of any candle: hover it and read 'ER' in this indicator's status line (top-left) or the Data Window. Independent of the ER chop filter value.
- **ats_c_x_on**: v9.35: candles in the last N whose close crossed the chart EMA20 or VWAP (vs the previous close). At or above the value = price whipping around the lines.
- **ats_c_sl_on**: v9.35: |HTF EMA20 now - N chart bars ago| / ATR below the value = the 15m trend line is flat.
- **ats_c_rg_on**: v9.35: (highest high - lowest low of the last N bars) / ATR below the value = tight box / squeeze.
- **ats_c_st_on**: v9.35: the latest chart-timeframe swings disagree -- Lower High with Higher Low (contracting) or Higher High with Lower Low (expanding) -- no clean trend.
- **ats_f_ext_on**: v8.65: no long when close is more than N x ATR above VWAP, no short when more than N x ATR below it (late, stretched entries). ATR = the Trade Setup ATR length on the chart timeframe.
- **ats_f_ext_sym**: v10.19: per-symbol version of the line above, e.g. "MGC 4, MES 8". - **ats_rp_sym**: v10.20: e.g. "MGC 5, MES 5". A listed symbol is ON at its own ATR value even with the checkbox off; 0 = OFF for that symbol; others use the checkbox and Y above. v10.23: per chart timeframe too, e.g. "MGC 3m 4, MGC 2m 0, MES 8" -- an entry with this chart's timeframe beats a symbol-only entry (2m and 3m can differ).

- **ats_rm_sym**: v10.47: e.g. "MES 3m 0.5, MGC 3m 1". Empty / unlisted / 0 = off (default). - **ats_rm_tp**: v10.47: OFF (default). ON = at the setup, if the first opposing level / OB (see the line above) is nearer than TP1, TP1 is moved to 1 tick before it -- but only when that still leaves at least this many x ATR. TP2 unchanged.
- **ats_sh_on**: v10.48: OFF = no shadows. ON (default since v10.49) = a trigger that passed every gate except the VWAP stretch filter is drawn as a shadow setup (dashed outline, faint fill, ✕ entry label) and tracked with the base exits until SL / trail / breakeven, HTF CBC flip or 16:00, then labelled "shadow +x". - **ats_f_flip_on**: v8.65: no new setup when the HTF CBC flipped at least N times within the last M HTF candles (the HTF is whipsawing inside a range).
- **ats_f_flip_sym**: v10.12: per-symbol version of the line above, e.g. "MGC 4, MES 0".
